# 双均线方向确认器（文华 WH6 麦语言）

一个把"交叉"和"方向"分开处理的技术指标示例：只在均线交叉**且**交叉后两根均线同向延伸时标记确认，用来演示麦语言里 `CROSSUP` / `CROSSDOWN` / `REF` / `DRAWTEXT` 的组合写法。

> 本文与代码仅讨论公式写法与逻辑结构，不构成任何交易建议。

---

## 1. 为什么写这个

均线交叉是最常被调用的信号函数，但 `CROSSUP(MA10,MA20)` 只判断"上穿发生"这一件事，不判断穿完之后两条线是不是还在往上走。结果就是横盘阶段一屏能刷出七八个交叉，肉眼根本分不清哪个是有效结构。

把"交叉"和"方向"拆成两个条件再取交集，是麦语言里最基础的一种信号过滤写法。这个仓库用它当作教学样本，顺带演示几个常用函数怎么组合。

## 2. 逻辑结构

```
交叉（事件） AND 同向延伸（状态）  →  确认标记
交叉（事件） AND 非确认            →  噪音标记
```

- **事件**：只用一根 K 线就成立，`CROSSUP` / `CROSSDOWN`
- **状态**：需要连续条件成立，靠 `REF` 做前后比较
- 两者的差别是：事件告诉你"刚刚发生了变化"，状态告诉你"变化之后还在延续"

## 3. 完整代码

```text
//双均线方向确认器  文华麦语言
//逻辑：交叉发生 且 交叉后双均线同向延伸，才标记"确认"
MA10:MA(CLOSE,10),COLORYELLOW;
MA20:MA(CLOSE,20),COLORWHITE;

//基础交叉
JC:=CROSSUP(MA10,MA20);
SC:=CROSSDOWN(MA10,MA20);

//同向延伸确认（交叉点之后，均线仍在同方向走）
JC_OK:=JC AND MA10>REF(MA10,1) AND MA20>REF(MA20,1);
SC_OK:=SC AND MA10<REF(MA10,1) AND MA20<REF(MA20,1);

DRAWTEXT(JC_OK,LOW-A*0.2,'多确认'),COLORRED;
DRAWTEXT(SC_OK,HIGH+A*0.2,'空确认'),COLORGREEN;

//未确认的交叉画小叉，提示"噪音"
DRAWICON(JC AND NOT(JC_OK),LOW,'ICO1');
DRAWICON(SC AND NOT(SC_OK),HIGH,'ICO2');
```

## 4. 逐行说明

| 写法 | 作用 | 容易踩的坑 |
|---|---|---|
| `MA10:MA(CLOSE,10),COLORYELLOW;` | 冒号输出变量，画线 | 用 `:=` 则不画线，只做中间变量 |
| `CROSSUP(A,B)` | A 上穿 B 的当根成立 | 只在"当根"成立，不是持续状态 |
| `REF(X,1)` | 取上一根的 X 值 | 第一根 K 线的 `REF` 为空值，比较结果为假，属正常 |
| `AND` | 逻辑与 | 麦语言不短路求值，右侧也会算 |
| `NOT(JC_OK)` | 取反 | 别写成 `!`，麦语言不认 |
| `DRAWTEXT(cond, price, '文字')` | 在指定价格位置写字 | 文字用单引号，中文可直接写 |
| `LOW-A*0.2` | 价格偏移，避免贴住 K 线 | `A` 是文华内置的报价单位，跨品种通用 |

## 5. 参数怎么调

代码里 10 / 20 是硬编码的，实际使用建议改成可调参数：

```text
N1:=10;  N2:=20;
MA1:MA(CLOSE,N1),COLORYELLOW;
MA2:MA(CLOSE,N2),COLORWHITE;
```

周期越大，标记越少、越滞后；周期越小，标记越密、噪音越多。这是任何过滤器都绕不开的取舍，不存在"最优参数"，只有"匹配你观察周期"的参数。

## 6. 常见报错

1. **`CROSSUP` 未定义** —— 不同版本函数名有差异，部分版本写作 `CROSS`，只判断上穿需自行写 `A>B AND REF(A,1)<=REF(B,1)`
2. **标记全部不显示** —— 先检查是不是用了 `:=` 输出，或者条件里 `AND` 两端类型不一致（一个是数值、一个是布尔）
3. **`DRAWICON` 图标不显示** —— 图标名要和版本内置的一致，不确定就改用 `DRAWTEXT`
4. **中文乱码** —— 文件保存编码选 ANSI 或 GBK，不要用 UTF-8

## 7. 另一个例子：ATR 跟踪止损线

同一个仓库里还有一个用 `HHV` / `LLV` / `MA` 组合的示例，演示怎么用波动幅度做动态参考线：

```text
TR1:=MAX(MAX(HIGH-LOW,ABS(HIGH-REF(CLOSE,1))),ABS(LOW-REF(CLOSE,1)));
ATR1:=MA(TR1,14);
STOP_L:HHV(HIGH,20)-3*ATR1,COLORRED;
STOP_S:LLV(LOW,20)+3*ATR1,COLORGREEN;
```
